# Maestro v0.5.0

Stato: **rilasciata, qualificata e verificata sul campo**.

## Perché conta

v0.5.0 segna il passaggio da solo runtime sperimentale a workstation AI
locale con un nucleo operativo dimostrato. Direct Chat legge zero o un file
esplicito; Controlled Mutation può sostituire un intervallo scelto
dall'utente soltanto dopo preview completa e approvazione allow-once.

## Cosa è stato validato

- asset pubblico Linux `amd64`, senza checkout o rebuild;
- Ollama locale e identità esatta dei due modelli qualificati;
- doctor 14/14;
- Direct Chat single-file con `qwen3.5:9b`;
- Controlled Mutation single-file/single-range PHP sotto `app/` con
  `qwen2.5-coder:14b`;
- deny e stale senza scritture, preview completa e apply atomico;
- qualifica release su WSL2/RTX 5070 e prova M38 su Linux nativo CPU-only.

M38 ha chiuso con completion 12/12, correttezza semantica 11/12, target e
preview 8/8, sei apply esatti e zero effetti vietati. L'errore semantico F02
resta registrato senza retry nel [report finale M38](../reports/milestone-38-final.md).

## Prova minima

```sh
version=v0.5.0
artifact="maestro-${version}-linux-amd64"
curl -fLO "https://github.com/Axtonno/maestro/releases/download/${version}/${artifact}.tar.gz"
curl -fLO "https://github.com/Axtonno/maestro/releases/download/${version}/${artifact}.tar.gz.sha256"
sha256sum -c "${artifact}.tar.gz.sha256"
tar -xzf "${artifact}.tar.gz"
cd "${artifact}"
./maestro doctor --mode all --config ./configs/maestro.v0.5.0-candidate.yaml
```

`0afcfe4d648edcde3caf4327c4f995606fb4c3974c05606e13f90dd8cff321d9`.

Il percorso completo è in [Installa e prova](../install-and-try.md); la
[pagina delle capacità correnti](../current-capabilities.md) è il riferimento
pubblico sintetico.

## Limiti noti

- il supporto Controlled Mutation vale solo nel perimetro testato e richiede
  sempre preview e approvazione esplicita;
- non sono supportati multi-file, selezione autonoma del target, agent
  autonomi, Windows nativo, altri provider o modelli/digest;
- non sono fornite sandbox, esecuzione comandi o garanzie di correttezza
  semantica;
- la qualifica CPU-only M38 riguarda il reference T490s osservato, non ogni
  hardware Linux `amd64`.

L'archive pubblico contiene inoltre un difetto documentale legacy: un
paragrafo anticipato sullo schema v3 e un riferimento insufficiente al nome
del profilo. Il file operativo è
`configs/maestro.v0.5.0-candidate.yaml`. Binario, manifest e configurazione
sono corretti; i sorgenti documentali sono stati corretti per le release
successive. L'asset v0.5.0 resta immutabile e non viene sovrascritto.

Il contratto completo del write-mode è in
[Controlled Mutation: perimetro supportato](../controlled-mutation-support.md).
