# Maestro v0.1.0 Release Notes

Data: 2026-08-15

Maestro v0.1.0 è la prima release installabile del runtime locale. Consente a
uno sviluppatore di analizzare e interrogare un progetto Laravel attraverso un
reference agent controllato e read-only.

## Percorso supportato

- Linux `amd64`;
- Ollama locale;
- `llama3.1:8b` per chat/tool calling;
- `embeddinggemma:latest` come fixture embedding;
- `agent.reference` con `workspace.list`, `workspace.read` e
  `workspace.search`;
- policy ufficiale `workspace_mutate: deny`.

## Installazione

Scaricare dalla release:

```text
maestro-v0.1.0-linux-amd64.tar.gz
maestro-v0.1.0-linux-amd64.tar.gz.sha256
```

Verificare il checksum prima di estrarre e seguire `docs/quick-start.md`
incluso nell'archive.

## Sicurezza

Il profilo supportato è read-only, ma Maestro resta trusted in-process e non è
una sandbox. Ollama riceve istruzione e contesto selezionato. Leggere
`docs/security-model.md` prima di usarlo su workspace sensibili.

## Limitazioni principali

llama.cpp, tool mutanti, approval mutativa e reference agent mutante sono
sperimentali/non supportati. Non sono inclusi multi-agent, persistence,
recovery, remote execution, shell/Git/Docker completi, secret manager o
packaging di estensioni terze.

CLI, configurazione e package Go sono contratti sperimentali della serie 0.x.
La matrice completa è in `docs/compatibility.md`; i problemi noti sono in
`docs/known-issues.md`.

## Evidenze di release

Il gate include build riproducibile, checksum, ispezione archive, installazione
pulita, `doctor`, `models`, `agents`, quick start live, cancellazione, hard
limit, shutdown bounded, suite, race detector e vet. Il report conclusivo è
pubblicato nel repository sorgente come
`docs/reports/milestone-8-final.md`.

Il gate finale include inoltre una regressione emersa durante la prima build:
una pseudo-tool-call stampata come JSON non può essere accettata come risposta
finale e deve attraversare l'interfaccia tool dichiarata entro i normali
limiti del run.
