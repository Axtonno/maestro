# Maestro v0.1.1 Release Notes

Data: 2026-08-15

Maestro v0.1.1 è una patch release read-only che corregge l'indicizzazione dei
workspace Laravel reali.

## Correzione

La v0.1.0 applicava al workspace Laravel la scan policy filesystem generica.
Asset generati comuni potevano quindi superare il limite per file di 1 MiB o
il limite complessivo di 64 MiB e terminare `maestro run` con
`execution_failed` prima della prima tool call.

Il plugin Laravel 0.3.1 indicizza ora soltanto le aree sorgente e i manifest
pertinenti. `public`, `storage`, dipendenze e directory nascoste restano fuori
dallo snapshot; i file sorgente sono bounded a 2 MiB e il totale resta bounded
a 64 MiB.

La patch intercetta inoltre le pseudo-tool-call JSON incorporate in una
risposta testuale quando nominano esattamente un tool dichiarato. Il loop
richiede una vera invocazione nel turno successivo entro gli stessi hard limit;
non traduce il testo in un effetto implicito.

## Compatibilità e sicurezza

- schema di configurazione invariato;
- CLI e API pubbliche invariate;
- profilo ufficiale ancora limitato a list/read/search;
- `workspace_mutate: deny` invariato;
- nessuna nuova autorità, mutazione o support claim provider/modello;
- llama.cpp resta sperimentale/non supportato.

## Evidenze

La correzione è coperta deterministicamente da un workspace con asset pubblico
oltre il limite generico e da prove live su due repository Laravel reali. I
workspace restano invariati; deadline, hard limit e SIGINT conservano i
terminali bounded della v0.1.0.

I dettagli sono nei report della Milestone 9 nel repository sorgente.
