# Maestro v0.3.0

Data candidate: 2026-08-29

Stato: packaging candidate qualificato; Milestone 17 completata con verdetto
`direct_chat_product_baseline`. Tag, release artifact finale e pubblicazione
restano azioni separate non ancora eseguite.

## Sintesi

v0.3.0 propone Direct Chat come primo percorso quotidiano single-file di
Maestro. L’utente sceglie esplicitamente zero o un file sotto il workspace; il
servizio effettua una completion diretta senza retrieval, tool o agent.

## Novità

- `maestro chat` con domanda posizionale o stdin bounded;
- `--file` single-file con containment e symlink policy fail-closed;
- `--stream` opt-in con output atomico;
- profilo strict v2 chat-only e `doctor --mode chat` a cinque check;
- context, thinking, timeout e limiti byte espliciti;
- reason code ed exit code chat stabili e diagnostica redatta;
- temperatura zero coerente fra complete e stream;
- packaging Linux `amd64` riproducibile con identità modello/digest nel
  manifest.

## Baseline candidata

- Ollama 0.33.1 locale su loopback;
- `qwen3.5:9b`, digest
  `6488c96fa5faab64bb65cbd30d4289e20e6130ef535a93ef9a49f42eda893ea7`;
- context 4096, thinking disabilitato, temperatura zero;
- streaming abilitato ma richiesto esplicitamente;
- file e output massimi 1 MiB.

F6.4 ha superato i gate deterministici, doctor 5/5, C0 3/3, C1 3/3,
complete/stream 2/2, qualità 4/5, containment, immutabilità e anti-leak. Lo
stesso archive installabile ha poi superato installazione pulita, doctor live,
no-file, complete/stream, traversal, symlink, SIGINT, deadline, immutabilità e
anti-leak nella Fase 7.

## Supporto candidato

- Linux `amd64`;
- Direct Chat Ollama single-file read-only;
- file locale esplicito e contained;
- complete e stream atomicamente validati.

## Non supportato

- `maestro agent`, l’alias `run` e ogni verified/reference agent;
- retrieval, indicizzazione o selezione multi-file;
- tool calling, tool di workspace e plugin di terze parti;
- Controlled Mutation, write, patch o approval;
- modelli/digest diversi, llama.cpp o endpoint remoti;
- sandbox, shell, Git, Docker, persistence o multi-agent.

## Upgrade da v0.2.0

Il profilo chat usa schema v2 e non deriva dalla configurazione v1 del
reference agent. Estrarre l’archive in una nuova directory, usare
`configs/maestro.chat.example.yaml`, impostare la root autorizzata e completare
`doctor --mode chat` prima della prima domanda.

v0.2.0 resta un artifact storico; v0.3.0 non qualifica retroattivamente il suo
reference agent e non riapre Controlled Mutation.

## Sicurezza

Il file selezionato viene disclosed al provider configurato. Maestro resta
trusted in-process e non è una sandbox. Verificare checksum, manifest,
provider, modello, digest e root prima dell’uso.
