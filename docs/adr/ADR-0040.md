# ADR-0040 — Modelli separati per Direct Chat e Controlled Mutation

- **Stato**: Accepted; Milestone 35 completata.
- **Data**: 2026-09-05.
- **Evidenza**: confronto congelato di tre profili e qualifica indipendente
  development/holdout. `qwen2.5-coder:14b`, digest
  `9ec8897f747e246e970bc5cfdda85d22f1123dc2e3d34978a010a75968716849`,
  supera tutti i gate M35; gli altri due profili non superano la selezione.
- **Decisione**: adottare un'assegnazione per capacità. `qwen3.5:9b` resta il
  profilo Direct Chat qualificato; il profilo M35 di `qwen2.5-coder:14b` è
  qualificato per la futura Controlled Mutation host-bound.
- **Conseguenza**: aprire M36 per integrare routing, configurazione, lifecycle,
  UX di approval, packaging e release readiness. Il claim pubblico v0.4.0 non
  cambia e una release v0.5.0 non è ancora autorizzata.
- **Vincolo**: identità modello, prompt, schema e parametri del profilo mutativo
  restano quelli congelati. Ogni modifica sostanziale richiede una nuova
  evidenza; le run M33–M35 non vengono ripetute o reinterpretate.
