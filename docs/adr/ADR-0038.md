# ADR-0038 — Target mutativo vincolato dall'host

- **Stato**: contratto implementato; qualifica M33 respinta.
- **Data**: 2026-09-05.
- **Decisione**: utente e Maestro possiedono path e intervallo inclusivo di
  righe. La selezione è congelata prima della generazione; il modello emette
  soltanto `propose` con `new_text` o `abstain`. Il fingerprint lega file,
  coordinate, span, sostituzione e diff; apply usa la candidate preparata e
  ricontrolla il digest dell'intero file.
- **Esito**: 12/12 output live validi, 7/10 proposte positive corrette,
  7/7 target e preview corretti, 7/10 approval attese raggiunte. Tre falsi
  negativi impediscono il completamento. Zero effetti non approvati, stale,
  fuori selezione o failure con effetti.
- **Conseguenza**: `host_bound_mutation_rejected`. L'implementazione resta
  interna e non estende il claim pubblico. Nessuna replica o tuning M33;
  nessun candidate, tag o release v0.5.0 autorizzato.
