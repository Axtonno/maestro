# ADR-0039 — Rigetto del profilo host-bound e modelli per capacità

- **Stato**: Accepted; Milestone 34 completata, ramo B.
- **Data**: 2026-09-05.
- **Evidenza**: audit M34 di prompt, payload, adapter, metadata e renderer;
  nessun conflitto concreto nelle istruzioni del percorso verificato.
  Le tre astensioni M33 restano false negative su trasformazioni determinabili.
- **Decisione**: `qwen3.5_9b_host_bound_mutation_profile_rejected`. Interrompere
  il tuning dello stesso profilo per Controlled Mutation; non ripetere M33
  e non creare un candidate M34 senza la precondizione del ramo A.
- **Conseguenza**: aprire M35 per selezionare un modello dedicato alla
  mutazione. Direct Chat conserva `qwen3.5:9b`; non è richiesto un modello
  unico per entrambe le capacità. Nessun ampliamento del claim o release
  v0.5.0 autorizzato.
- **Limite**: decisione sul profilo osservato, non prova della causa interna
  delle astensioni o di un'impossibilità universale del modello.
